# מסמך אפיון – אתר מתכונים משותפים

> המסמך שאושר לפני הבנייה, עם השלמות קטנות שנוספו במימוש (מסומנות ב-🆕).

## א. תיאור הפרויקט

**שם:** מתכונים משותפים
**מטרה:** מקום אחד מסודר לשמירת מתכונים אישיים, עם אפשרות לשתף מתכונים עם משתמשים אחרים, לחפש, לסנן ולשמור מתכונים אהובים.
**קהל יעד:** כל מי שאוהב לבשל.

| תפקיד | תיאור |
|---|---|
| משתמש רגיל (`USER`) | מנהל את המתכונים שלו, צופה במתכונים ציבוריים, שומר מועדפים |
| מנהל (`ADMIN`) | כל מה שמשתמש רגיל יכול, וגם ניהול קטגוריות ומחיקת מתכונים ציבוריים לא ראויים |

כל האתר דורש התחברות, חוץ מהרשמה והתחברות.

## ב. מסכים

| # | מסך | מה מוצג | פעולות | מי |
|---|---|---|---|---|
| 1 | הרשמה | שם, אימייל, סיסמה | הרשמה + התחברות אוטומטית | אורח |
| 2 | התחברות | אימייל, סיסמה | התחברות | אורח |
| 3 | מתכונים ציבוריים | כרטיסים: תמונה, שם, קטגוריה, זמן, קושי, כשרות, יוצר | חיפוש, סינון, מיון, עמודים, מועדפים | מחובר |
| 4 | המתכונים שלי | המתכונים שלי + סימון פרטי/ציבורי | כמו 3 + סינון פרטי/ציבורי, עריכה, מחיקה | מחובר |
| 5 | צפייה במתכון | כל הפרטים | מועדפים; לבעלים עריכה ומחיקה; למנהל מחיקה של ציבורי | מחובר |
| 6 | הוספת מתכון | טופס + בחירת תמונה | שמירה, העלאת תמונה | מחובר |
| 7 | עריכת מתכון | הטופס עם הנתונים | עדכון, החלפת/הסרת תמונה | בעלים |
| 8 | המועדפים שלי | המתכונים ששמרתי | הסרה, כניסה למתכון | מחובר |
| 9 | ניהול קטגוריות | קטגוריות + מספר מתכונים | הוספה, שינוי שם, מחיקה (רק ריקה) | מנהל |

## ג. הרשאות

| פעולה | אורח | USER | ADMIN |
|---|:---:|:---:|:---:|
| הרשמה והתחברות | ✅ | ✅ | ✅ |
| צפייה בקטגוריות | ❌ | ✅ | ✅ |
| ניהול קטגוריות | ❌ | ❌ | ✅ |
| צפייה במתכונים ציבוריים | ❌ | ✅ | ✅ |
| צפייה במתכון פרטי שלי | ❌ | ✅ | ✅ |
| צפייה במתכון פרטי של אחר | ❌ | ❌ | ❌ |
| הוספת מתכון | ❌ | ✅ | ✅ |
| עריכה והעלאת תמונה למתכון שלי | ❌ | ✅ | ✅ |
| עריכת מתכון של אחר | ❌ | ❌ | ❌ |
| מחיקת מתכון שלי | ❌ | ✅ | ✅ |
| מחיקת מתכון ציבורי של אחר | ❌ | ❌ | ✅ |
| מחיקת מתכון פרטי של אחר | ❌ | ❌ | ❌ |
| ניהול המועדפים שלי | ❌ | ✅ | ✅ |

- ההרשמה יוצרת תמיד USER. מנהל נוצר דרך Seed או משתני סביבה.
- הזהות נקבעת לפי ה-Token בלבד. 🆕 התפקיד נטען מחדש ממסד הנתונים בכל בקשה.
- מתכון פרטי של אחר מחזיר 404, כדי לא לחשוף שהוא קיים.

## ד. מסד הנתונים

### User – `users`
| שדה | טיפוס | חובה | הערות |
|---|---|:---:|---|
| id | Int (SERIAL) | ✅ | PK |
| name | VARCHAR(50) | ✅ | CHECK: 2–50 תווים |
| email | VARCHAR(254) | ✅ | UNIQUE, נשמר באותיות קטנות |
| password_hash | TEXT | ✅ | bcrypt, לא מוחזר ב-API |
| role | enum Role (USER/ADMIN) | ✅ | ברירת מחדל USER |
| created_at, updated_at | TIMESTAMP | ✅ | אוטומטי |

### Category – `categories`
| שדה | טיפוס | חובה | הערות |
|---|---|:---:|---|
| id | Int | ✅ | PK |
| name | VARCHAR(40) | ✅ | UNIQUE, CHECK: 2–40 תווים (🆕 ייחודיות גם ללא תלות באותיות גדולות/קטנות, בשרת) |
| created_at, updated_at | TIMESTAMP | ✅ | |

### Recipe – `recipes`
| שדה | טיפוס | חובה | הערות |
|---|---|:---:|---|
| id | Int | ✅ | PK |
| title | VARCHAR(100) | ✅ | CHECK: 2–100 |
| description | VARCHAR(500) | ✅ | CHECK: 5–500 |
| ingredients | TEXT | ✅ | CHECK: 1–5,000 |
| instructions | TEXT | ✅ | CHECK: 1–10,000 |
| prep_time_minutes | INT | ✅ | CHECK: 1–1,440 |
| difficulty | enum (EASY/MEDIUM/HARD) | ✅ | |
| servings | INT | ✅ | CHECK: 1–100 |
| kosher_type | enum (MEAT/DAIRY/PAREVE) | ✅ | |
| is_public | BOOLEAN | ✅ | ברירת מחדל false |
| image_url | TEXT | ❌ | |
| image_public_id | TEXT | ❌ | פנימי, לא מוחזר ב-API |
| author_id | INT | ✅ | FK → users, ON DELETE CASCADE |
| category_id | INT | ✅ | FK → categories, ON DELETE RESTRICT |
| created_at, updated_at | TIMESTAMP | ✅ | |

אינדקסים: `author_id`, `category_id`, `(is_public, created_at)`.

### Favorite – `favorites`
| שדה | טיפוס | חובה | הערות |
|---|---|:---:|---|
| user_id | INT | ✅ | FK → users, CASCADE |
| recipe_id | INT | ✅ | FK → recipes, CASCADE |
| created_at | TIMESTAMP | ✅ | |

PK מורכב: `(user_id, recipe_id)`. אינדקס: `recipe_id`.

### קשרים
- User 1 ← רבים Recipe
- Category 1 ← רבים Recipe
- User רבים ↔ רבים Recipe (דרך Favorite)

🆕 השלמות במימוש:
- במתכון מוחזרים גם `canEdit` ו-`canDelete`, כדי שצד הלקוח ידע אילו כפתורים להציג.
- ב-`PUT /api/recipes/:id` השדה `isPublic` חובה (עדכון מלא), כדי שמתכון ציבורי לא יהפוך לפרטי בטעות.
- ברשימת המועדפים לכל פריט יש `favoritedAt`.
- הגבלת ניסיונות התחברות (429).
